# اختيار المشاريع ضمن ميزانية

**BIA601 — الخوارزميات الذكية — الوظيفة الأولى (F25) — المجموعة 2**

المستودع: https://github.com/alshaaermohammad-cmd/Algorithms_Project

يقارن المشروع GA وBinary PSO وACO لحل مسألة الحقيبة الثنائية، مع DP وGreedy للمقارنة. جميع الخوارزميات مكتوبة داخل المشروع.

## المتطلبات والتشغيل

استخدم Python 3.12 أو أحدث. من مجلد project:

```text
python -m pip install -r requirements.txt
python tuning.py
python main.py
python verify.py
```

النتائج المرفقة تخص 20 تشغيلة لكل خوارزمية ولكل مسألة. تظهر رسالة عند انتهاء كل إعداد أو مسألة. تشغيل الضبط والتجارب الكاملة يستغرق عدة دقائق.

لتجربة سريعة دون تغيير النتائج المرفقة:

```text
python main.py --runs 2 --output ../trial_results
```

لإعادة الثابت العشوائي 0 على المسائل الـ27 ومقارنة الحلول ومسارات التقارب بالنتائج المرفقة:

```text
python verify.py --rerun
```

## التجارب

- الأحجام: 20 و100 و500 مشروع.
- الأنواع: عوائد غير مرتبطة بالكلف، وارتباط ضعيف، وارتباط قوي.
- ثلاث مسائل لكل حجم ونوع، أي 27 مسألة.
- 20 تشغيلة للخوارزمية على المسألة، بثوابت من 0 إلى 19.
- الضبط على ست مسائل منفصلة بثوابت تبدأ من 1000، وخمس تشغيلات لكل إعداد.
- حجم الجماعة أو السرب أو المستعمرة 50، و15050 استدعاء لدالة الهدف في التشغيلة.
- التعادلات في الفرز تحسم بترتيب الفهارس.

## قراءة النتائج

Gap هو مئة مضروبة في الفرق بين العائد الأمثل والعائد الناتج، مقسوما على العائد الأمثل. الأقل أفضل. النجاح الأمثل يعني مساواة حل DP تماما.

هدف التقارب بلوغ 99.9% من العائد الأمثل. عند الفشل يبقى target_iteration فارغا، ويسجل target_reached بالقيمة False. يحسب target_iteration_mean للتشغيلات التي وصلت فقط، ويعرض target_hits عددها من الإجمالي. التكرار 0 هو تقييم الجماعة الأولى أو المستعمرة الأولى.

يمثل gap_std متوسط الانحرافات المعيارية داخل المسائل الثلاث مع ddof=0، لقياس تغير النتيجة عند تكرار الخوارزمية على المسألة نفسها. الذاكرة هي ذروة tracemalloc في تشغيل إضافي بالثابت 0 لكل مسألة، ثم متوسط المسائل. الوحدة KiB، ولا يمثل القياس كامل ذاكرة عملية Python. الزمن مقاس بصورة منفصلة عن التتبع، ويتغير بحسب الجهاز.
